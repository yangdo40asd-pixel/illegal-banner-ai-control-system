1. 화면이 시스템 안에서 어디에 오는지

  [앱 Shell]  ← 새로 만듦 (좌측 메뉴 5개)

    ├─ 통계/리포트        ← 로드맵
    └─ 시스템 설정        ← 로드맵

  신고 접수 목록 ≠ 실시간 모니터링
    · 모니터링: WebSocket + CCTV + AI 실시간 탐지 (이미 있음)
    · 신고목록: 시민 신고 건 CRUD + 행정 상태 머신 (새로 만듦)

6. Phase D — 상태별 액션 버튼
================================================================================

  [DataTemplate — 액션 컬럼]

    DataTrigger / Converter로 상태별 버튼 노출:

    | 상태     | 버튼           | Command                    |
    |----------|----------------|----------------------------|
    | 처리대기 | "접수"         | AcceptReportCommand        |
    | 처리중   | "이어서 처리"  | ContinueProcessCommand     |
    | 처리완료 | "결과 보기"    | ViewResultCommand          |
    | 반려     | "사유 보기"    | ViewRejectReasonCommand    |

  [ReportListViewModel 로직]

    AcceptReportCommand:
      · 상태 Pending → InProgress
      · 담당자 = 현재 로그인 사용자 (임시: "김무주" 하드코딩)
      · Repository.Update

    ContinueProcessCommand:
      · 상세 패널 열기 + (향후) 단속 처리 화면으로 네비

    ViewResultCommand / ViewRejectReasonCommand:
      · 하단 패널 또는 팝업

  [완료 기준]
    □ 상태별 올바른 버튼만 보임
    □ "접수" 클릭 시 상태·담당자 변경 + KPI 갱신

## 🚀 작업 우선순위 (Execution Steps)

### [Step 1] 뼈대: 네비게이션 + 레이아웃 Grid
* 작업:
  1. `Views/StatisticsReportView.xaml` (UserControl) 생성.
  2. `MainViewModel.NavigateCommand`에 `Statistics` 분기 추가.
  3. 6행 Grid: 기간바 / KPI / 차트상좌우 / 차트하좌우 / 하단좌우 / 드릴다운(접이식).
* 검증: 사이드바 "통계/리포트" 클릭 시 화면 전환, 빈 카드 영역만 표시.

### [Step 2] 데이터 뼈대: ViewModel + Mock
* 작업:
  1. `ViewModels/StatisticsReportViewModel.cs` 생성.
  2. `Models/Statistics*.cs` (위 모델 설계) 정의.
  3. `Services/IStatisticsRepository.cs` + `MockStatisticsRepository.cs` — 목업 수치 하드코딩.
  4. `DataContext` 바인딩.
* 검증: 디버그 출력 또는 임시 TextBlock으로 KPI 숫자 147, 4,820만원 확인.

### [Step 3] 상단 기간 선택 바
* 작업:
  1. 탭 4개: 주간/월간/분기/연간 — `SelectedPeriod` 바인딩, 선택 시 파란 강조.
  2. `ComboBox` 상세 기간: "2026년 5월", "2026년 4월" … (기간 타입에 따라 항목 변경).
  3. `CheckBox` "전년도/전월과 비교" → `CompareWithPrevious` (KPI·막대 오버레이 토글).
  4. 우측 버튼: `DownloadReportCommand`, `PrintCommand` (1차: MessageBox 데모).
* 검증: 탭·드롭다운 변경 시 `PeriodLabelText` = "2026년 5월 비교" 갱신.

### [Step 4] KPI 카드 5개
* 작업:
  1. `EnforcementStatusView`와 동일한 UniformGrid + DropShadow 카드 스타일 재사용.
  2. 증감 화살표: ▲ 초록 / ▼ 빨강 `PackIcon` + 보조 텍스트 바인딩.
  3. 비교 체크 OFF 시 증감·전월 텍스트 Collapsed.
* 검증: 목업과 동일 수치·색상 (147건 파랑, 4,820만원 빨강, 12명 주황).

### [Step 5] 차트 인프라 + 좌상 막대 (지역별)
* 작업:
  1. NuGet: `LiveChartsCore.SkiaSharpView.WPF` 추가.
  2. `UserControl` 또는 View 내 `lvc:CartesianChart` — 강남/서초/송파/마포/기타 막대.
  3. `CompareWithPrevious=true` 시 회색 막대(전월) + 컬러 막대(당월) 그룹 오버레이.
  4. 범례: ● 당월 ● 전월.
* 검증: Y축 0~55, 강남구 47 막대 높이 목업과 유사.

### [Step 6] 우상 도넛 (내용분류별 비율)
* 작업:
  1. `lvc:PieChart` InnerRadius 도넛, 중앙 "총 147건".
  2. 6분류 색상 팔레트 (빨강·주황·노랑·초록·보라·회색).
  3. 우측 범례: 분류명 + N건 (M%).
  4. `PieSlice Click` → `SelectedCategory` 설정 (드릴다운 트리거).
* 검증: 42%/28%/18%/12% 비율 표시, 클릭 시 ViewModel 프로퍼티 변경 로그.

### [Step 7] 좌하 라인 (요일/시간대) + 우하 Top 5 (가로 막대)
* 작업:
  1. 라인 차트: X=0~23시, 시리즈 2개 (평일 보라, 주말 점선 또는 다른 색).
  2. 15~16시 피크 구간 `Section` 또는 Annotation 강조.
  3. Top 5: `ListView` + `ProgressBar` 가로 막대 (순위 색상 그라데이션) — 차트 없이 WPF만으로도 가능.
  4. "전체 명단 보기 >" Hyperlink (데모).
* 검증: 피크 시간대 시각적 강조, Top 1 강○○ 8건 표시.

### [Step 8] 하단 2열: 월별 추이 + 담당자 실적
* 작업:
  1. 좌: `CartesianChart` ColumnSeries(건수) + LineSeries(누적 과태료, 우측 Y축).
  2. 우: `DataGrid` 또는 ListView — 1등 행 배경 `#FEF3C7` 강조 + ★ 아이콘.
* 검증: 5월 147건 막대 + 라인 꺾임, 김무주 1등 행 강조.

### [Step 9] 내용분류 드릴다운 패널
* 작업:
  1. 도넛 클릭 시 하단 또는 우측 슬라이드 패널 `Visibility=Visible`.
  2. `ContentCategory.Politics` → 정당별 / 후보자별 `DrillDownItem` 목록.
  3. `ContentCategory.Commercial` → 부동산·학원·병원·음식점 서브 차트(작은 막대) 또는 테이블.
  4. `ClearDrillDownCommand` 로 전체 통계 복귀.
* 검증: "상업/부동산" 클릭 → 4개 업종 세부 건수 표시.

### [Step 10] 리포트 출력 + DB 연동 준비
* 작업:
  1. `ClosedXML`로 KPI+표 요약 xlsx 생성 (이미 패키지 있음).
  2. `QuestPDF`로 1페이지 요약 PDF (선택).
  3. `IStatisticsRepository` 인터페이스만 두고 Mock → 추후 SQLite `banner_tracking.db` / 단속 테이블 연동.
* 검증: 리포트 다운로드 클릭 시 xlsx 파일 저장 성공.

## 4. [완료] 3단계: 통합 파이프라인 구동 확인

### 파이프라인 동작 방식

```
📸 이미지 입력
    ↓
[STEP 1] YOLO — 현수막 위치(바운딩 박스) 탐지
    ↓
[STEP 2] 이미지 2종 크롭
    ├── 배경 크롭: 현수막 + 주변 60% 여백 (전봇대·나무·끈 확인용)
    └── 확대 크롭: 현수막만 1024px 업스케일 (글자 선명화)
    ↓
[STEP 3] Qwen2.5-VL — 두 장 동시 입력 → 보고서 생성
    ↓
[STEP 4] 키워드 정확 매칭으로 불법/합법 판정
    ├── "최종판정: 불법" 감지 → 🔴 빨간 박스
    └── "최종판정: 합법" 감지 → 🟢 초록 박스
    ↓
[STEP 5] 결과 이미지 저장 (results_qwen25/)
```

### AI 출력 형식 (보고서 구조)

```
텍스트: (현수막에 적힌 글자)
설치환경: (나무에 끈으로 묶임 / 금속 게시대에 고정 등)
최종판정: 불법 또는 합법
판정근거: (판단 이유 한 문장)
```

### 5장 샘플 테스트 결과

*   **성공**: 5장 / **실패**: 0장
*   텍스트 추출, 설치환경 묘사, 불법 판정 모두 정상 동작 확인
*   실제 판독 예시:
    > 텍스트: `봄맞이 빅세일`  
    > 설치환경: 현수막은 나무에 끈으로 묶여 있습니다.  
    > 최종판정: **불법**  
    > 판정근거: 나무에 끈으로 묶인 경우는 정식 게시대 설치가 아닌 것으로 판단됩니다.

## 2. 변경사항 이력 (v1.0 → v2.0)

### [변경] VLM 모델 교체

| 항목 | v1.0 (구) | v2.0 (현재) | 변경 이유 |
| :--- | :--- | :--- | :--- |
| VLM 모델 | `microsoft/Florence-2-large-ft` | `Qwen/Qwen2.5-VL-3B-Instruct` | Florence-2 한국어 OCR 완전 불가 |
| 모델 크기 | ~1.5GB | ~6GB | 성능 향상을 위한 대형 모델 채택 |
| VRAM 점유 | ~3GB | ~3.5GB (bfloat16) | RTX 3080 10GB 내 안정 구동 |
| 양자화 | 불필요 | 불필요 | 3B 크기로 여유 있음 |
| 한국어 OCR | ❌ 불가 | ✅ 정상 작동 | 핵심 기능 해결 |
| 판정 방식 | 단순 키워드 | Few-shot 프롬프팅 | 형식 준수율 향상 |

### [변경] YOLO 모델 명칭

| 항목 | v1.0 | v2.0 |
| :--- | :--- | :--- |
| YOLO 모델 | YOLOv26**n** (나노) | YOLOv26**s** (스몰) | 
| 성능 | 미학습 | mAP50 **99.2%** 달성 |
| 모델 경로 | 미정 | `yolo26s/runs/banner_s_20260506_1909/weights/best.pt` |

### [변경] 기술 스택

| 구분 | v1.0 | v2.0 |
| :--- | :--- | :--- |
| **Reasoning** | Microsoft Florence-2 | **Qwen/Qwen2.5-VL-3B-Instruct** |
| **Prompt 방식** | 단순 지시문 | **Few-shot 예시 포함 구조화 프롬프트** |
| **분석 방식** | 단일 크롭 | **이중 크롭 (배경용 + OCR 확대용)** |

## 3. AI 추론 파이프라인 (현행 v2.0)

```
📸 이미지 / 영상 프레임 입력
        │
        ▼
[STEP 1] YOLOv26s — 현수막 위치 탐지 (바운딩 박스)
        │
        ▼
[STEP 2] 이중 크롭 생성
   ├── 배경 크롭: 현수막 + 주변 60% 여백 (설치환경 파악용)
   └── 확대 크롭: 현수막 영역만 1024px 업스케일 (OCR용)
        │
        ▼
[STEP 3] Qwen2.5-VL-3B — 두 장 동시 분석
   프롬프트: Few-shot 예시 포함, 4개 항목 구조화 출력
   출력 형식:
     텍스트: (현수막 글자)
     설치환경: (나무 끈 묶임 / 게시대 고정 등)
     최종판정: 불법 또는 합법
     판정근거: (이유 한 문장)
        │
        ▼
[STEP 4] 키워드 정확 매칭 판정
   "최종판정: 불법" → 🔴 불법
   "최종판정: 합법" → 🟢 합법
        │
        ▼
[STEP 5] 결과 이미지 저장 / FastAPI로 전송 (예정)
```

## 4. 5대 핵심 화면 (변경 없음)

### [S1] 전문가 로그인
- ID/PW 기반 인증, 공무원/관리자 권한 부여

### [S2] 실시간 모니터링
- 멀티 채널 CCTV 스트리밍 (Grid View)
- YOLO Overlay: 현수막 위치 실시간 바운딩 박스

### [S3] 의심 건수 목록 (Alert Dashboard)
- 탐지 시간, 썸네일, AI 판단 등급 카드 리스트
- 날짜/구역/불법 유형별 필터링

### [S4] 공무원 정밀 확인 (Precision Audit)
- Dual View: 원본 전체 + 현수막 확대 비교
- AI Report: VLM 상세 분석 보고서
- 최종 결정: [정상] [불법] [보류] 버튼

### [S5] 시스템 설정
- CCTV RTSP 주소 등록/관리
- AI 임계값 조절
- VLM 프롬프트 커스터마이징

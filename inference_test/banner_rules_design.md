# 현수막 유형별 AI 규격 설정 및 불법 판정 알고리즘 설계서
본 설계서는 인천광역시 옥외광고물 조례 및 2024-2026 개정 옥외광고물법령에 근거하여, AI 엔진(FastAPI) 및 WPF 클라이언트에서 각 현수막의 불법 규격을 수치적으로 제어하고 판정하기 위한 알고리즘 가이드입니다.

## 1. 현수막 유형별 규격 및 검출 매트릭스

AI가 이미지 내에서 현수막 종류를 식별하기 위해 사용하는 물리적 특징 및 텍스트 힌트 매트릭스입니다.

| 현수막 종류 | 기준 종횡비 (가로:세로) | VLM 검출 키워드 (설치환경) | 텍스트 핵심 힌트 (Text Clue) |
|---|---|---|---|
| **A. 지정게시대** | **8.5:1 ~ 10.5:1** (매우 길고 얇음) | 철제/금속 프레임, 거치대 틀 내부 설치 | 상업 홍보, 분양, 개업 등 |
| **B. 가로등 현수기** | **1:2.5 ~ 1:3.2** (세로형 구조) | 가로등 기둥 밀착, 가로등 좌우 대칭 | 공연, 예술, 체육 행사 정보 |
| **C. 건물 외벽형** | **1.5:1 ~ 3:1** (대형 판형) | 건물 벽면 부착, 창문 침범 여부 | 백화점 행사, 아파트 분양 정보 |
| **D. 정당 현수막** | **4:1 ~ 5:5:1** (위아래가 넓음) | 가로등/전봇대 끈 연결, 펜스 거치 | 정당명, 정치인 이름, 정당 로고 |
| **E. 일반 무단현수막** | **5.5:1 ~ 6.5:1** (뚱뚱한 비율) | 가로수, 신호등, 울타리에 노출된 끈 | 상업 광고, 불법 대출, 분양 홍보 |

## 2. 불법 규격 설정 및 세부 판정 알고리즘 (백엔드 로직)

### ① 종횡비(Aspect Ratio) 기반 비정상 규격 필터링
YOLO 검출 박스 $B = [x_1, y_1, x_2, y_2]$에 대하여 가로 $W = x_2 - x_1$, 세로 $H = y_2 - y_1$ 일 때, 비율 $R = W / H$를 구합니다.
*   **가로등 현수기 이상 규격 감지**: $R > 0.5$ (가로등에 달렸는데 가로 폭이 너무 넓음) 이면 **규격 미달 불법** 유추.
*   **지정게시대 이상 규격 감지**: 게시대 틀에 있으나 $R < 7.0$ 이면 규격 위반 유추.

### ② 픽셀 분석 기반 바탕색(Color) 규제 계산
현수막 크롭 이미지의 HSV 색공간에서 자극적인 원색 영역의 비율을 계산합니다.
```python
# 알고리즘 의사코드 (Color Filter)
def check_color_violation(crop_img):
    # HSV 변환 후 Red, Blue, Yellow, Black 영역 마스킹
    red_mask = cv2.inRange(hsv, lower_red, upper_red)
    blue_mask = cv2.inRange(hsv, lower_blue, upper_blue)
    yellow_mask = cv2.inRange(hsv, lower_yellow, upper_yellow)
    black_mask = cv2.inRange(hsv, lower_black, upper_black)
    
    violation_pixels = cv2.countNonZero(red_mask | blue_mask | yellow_mask | black_mask)
    total_pixels = crop_img.shape[0] * crop_img.shape[1]
    
    violation_ratio = violation_pixels / total_pixels
    # 인천시 조례: 해당 색상 바탕면적 50% 이상 시 불법
    return violation_ratio > 0.50
```

### ③ GPS 구역 및 VLM 결합형 '스쿨존/소방시설' 차단
*   **위치 동기화**: 단속 카메라의 GPS 위경도 정보가 미리 지정된 인천시 스쿨존(어린이 보호구역) 및 소방용수시설 5m 반경 데이터베이스에 속해 있는지 대조합니다.
*   **판정**: 해당 구역 내부인 경우, VLM이 `현수막종류: 정당현수막`으로 판정하더라도 **상위법 금지 구역 위반(⑩, ⑪번 항목)에 걸려 즉시 불법** 처리됩니다.

## 3. WPF 설정(S5)을 통한 사용자 조율 값 (Parameters)

WPF 단속 클라이언트에서 관리자(공무원)가 세부 단속 임계치를 튜닝할 수 있도록 설정 파라미터를 노출합니다.

1.  **관할 구역 프리셋 설정 (Preset)**
    *   `연수구/미추홀구/부평구` 선택 시: 표준 대형 게시대 기준 규격 가로 **7.1m** 자동 세팅
    *   `서구/남동구/중구` 선택 시: 표준 중형 게시대 기준 규격 가로 **6.0m** 자동 세팅
2.  **색채 단속 민감도 (Color Limit)**: 기본값 50% (조례 기준). 30%~70% 조절 가능.
3.  **정당현수막 경과일 임계치**: 기본값 15일. VLM이 기재된 날짜를 추출해 오늘 날짜와 계산하여 15일이 초과되었는지 계산함.

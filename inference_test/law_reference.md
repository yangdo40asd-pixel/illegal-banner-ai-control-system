# 인천광역시 현수막 AI 단속 표준 규정집 (2026.05)
인천광역시 조례 및 개정 옥외광고물법령에 근거하여 AI 분석 엔진이 판정해야 하는 불법/합법 규격을 명확한 의사결정 규칙으로 정의합니다.

---

## 1. 정당 현수막 판단 규정 (RULE 1)
*   **식별 대상**: 정당명(국민의힘, 더불어민주당 등) 또는 당원협의회장, 국회의원 등의 정치인 이름이 명기된 현수막.
*   **판독 로직**:
    ```
    IF [설치구역] == 어린이보호구역(스쿨존) OR 소방시설 5m 이내:
        RETURN 불법 (사유: 금지 구역 설치 위반)
    ELIF [지상고] == 교통요충지(교차로/횡단보도/버스정류장 주변)에서 하단 높이 2.5m 미만:
        RETURN 불법 (사유: 안전 높이 미확보)
    ELIF [게시일수] > 15일:
        RETURN 불법 (사유: 게시 기간 만료)
    ELSE:
        RETURN 합법
    ```

---

## 2. 일반 현수막 판단 규정 (RULE 2)
*   **식별 대상**: 정당 현수막(RULE 1)이 아닌 모든 일반 상업/행정용 현수막.
*   **판독 로직**:
    ```
    IF [설치장소] != 지정게시대:
        RETURN 불법 (사유: 지정게시대 외 불법 장소 설치)
    ELIF [바탕색 원색비율] >= 50% (적색, 청색, 황색, 흑색의 면적 합):
        RETURN 불법 (사유: 조례 기준 바탕색 규제 위반)
    ELIF [조명장치] == 있음 (네온, 전광류, LED 사용):
        RETURN 불법 (사유: 조명 사용 금지 조항 위반)
    ELIF [내용] == 혐오, 비방, 모욕, 불법사채, 음란성 광고:
        RETURN 불법 (사유: 청소년 유해 및 공공질서 위반)
    ELSE:
        RETURN 합법
    ```

---

## 3. 가로등 현수기 판단 규정 (RULE 3)
*   **식별 대상**: 가로등 기둥에 세로 형태로 매달려 표시하는 현수막.
*   **판독 로직**:
    ```
    IF [가로크기] > 60cm OR [세로크기] > 170cm:
        RETURN 불법 (사유: 가로등 현수기 규격 초과)
    ELIF [밀착도] > 10cm (가로등 기둥과의 간격):
        RETURN 불법 (사유: 기둥 밀착 고정 위반)
    ELIF [지상고] < 2.0m (간선도로변은 2.5m 미만):
        RETURN 불법 (사유: 안전 지상고 미확보)
    ELIF [내용] == 상업 광고물 (학술, 예술, 체육, 국가 행사 외 목적):
        RETURN 불법 (사유: 표시 내용 위반)
    ELSE:
        RETURN 합법
    ```

---

## 4. 건물 외벽 및 가림막 현수막 판단 규정 (RULE 4)
*   **건물 외벽 판독**:
    - 하단 지면 높이 4m 이상 여부 체크
    - 10층 높이 이하 여부 체크
    - 벽면 단면적의 1/3 초과 여부 체크
    - 위반 사항 발생 시 즉시 불법 판정
*   **공사 가림막 판독**:
    - 공사 관련 정보(시공자, 공사개요 등) 또는 공익 문구 이외의 상업적 광고 포함 시 불법 판정
    - 10층 높이 이하 여부 체크

🎯 프로젝트 개요
1. 의도 (왜 이걸 만들려고 했나?)
처음에 "공익적이고 사회적 이슈를 다루는 걸 교수님이 좋아하신다"는 말씀에서 출발했습니다.
우리가 정한 방향은 단순한 기술 구현이 아니라, "실제 사회 문제를 기술로 해결하는 접근법" 을 보여주는 것입니다.

2. 주제 선정 과정
불법 광고물 → 불법 현수막 → 불법 튜닝 차량 등 여러 아이디어를 거친 끝에, 다시 "불법 현수막/광고물 단속 지원 시스템" 으로 정착했습니다.

특히 2026년 5월은 6월 지방선거를 앞둔 시기라 정치 현수막이 기승을 부리는 때라 시의성이 뛰어납니다.

3. 핵심 문제 인식
"YOLO 같은 AI는 현수막의 위치는 알려줘도, 그게 합법인지 불법인지는 모른다."
이유: 법과 조례는 픽셀 데이터에 내재된 속성이 아니기 때문에, 맥락적 판단(Contextual Reasoning)이 필요합니다.

💡 우리의 해결 접근법
"Human-in-the-loop"
AI가 모든 걸 자동으로 판단하는 게 아니라,
AI는 의심 사례만 빠르게 걸러주고 → 사람(공무원)이 최종 판단을 내리도록 돕는 시스템

🛠 기술 스택 (어떤 기술을 어떻게 쓰나?)
단계	기술	역할
1단계: 탐지	YOLO	CCTV 영상에서 "현수막 의심" 프레임을 실시간으로 캡처
2단계: 시간 필터	ByteTrack + 자체 로직	1시간 기준으로 지속 탐지된 것만 "진짜 의심"으로 분류 (바람에 날리는 비닐 걸러내기)
3단계: 맥락 분석	VLM (Vision-Language Model)	YOLO가 찍은 이미지를 분석해 "왜 불법 의심인가"를 텍스트로 설명
4단계: 관제 대시보드	WPF	위 모든 정보를 공무원이 직관적으로 보고 최종 판단하는 UI
🖥️ WPF의 역할과 강점
왜 하필 WPF인가?
WPF 강점	프로젝트 적용
실시간 데이터 바인딩 (MVVM)	새 의심 현수막 탐지 시 목록과 지도가 자동 갱신
DataTemplate	각 신고를 이미지+요약+신뢰도 게이지가 담긴 카드 형태로 표시
멀티패널 동기화	신고 목록 클릭 → 지도가 해당 위치로 부드럽게 이동/확대
커스텀 애니메이션	심각도에 따라 카드 점멸, 패널 슬라이드 등
하드웨어 가속 렌더링	다수의 CCTV 영상을 부드럽게 동시 표시
🎯 앱의 목적
"불법 현수막 단속 공무원의 업무 효율을 극대화하는 AI 보조 관제 대시보드"

구체적인 목표:
실시간 모니터링: 여러 CCTV를 동시에 보지 않아도, AI가 의심 사례만 추려서 알려줌

맥락 정보 제공: 단순히 "현수막 발견"이 아니라, "전봇대 부착, 상업 문구 포함, 합법 게시대와 127m 이격" 같은 분석 결과를 제공

최종 판단 지원: 공무원이 지도, 법규, 원본 이미지를 한 화면에서 비교하며 "합법/불법/재검토" 결정을 내릴 수 있음

행정 업무 연계: 과태료 산정, 처리 이력 관리, 지역별 통계까지 통합

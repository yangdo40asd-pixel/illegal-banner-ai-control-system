# 단속 처리 현황 화면 구현 계획서 (우선순위 및 1-by-1 원칙 적용)

## 🎯 핵심 원칙: 1-by-1 (단계별 검증)
복잡한 화면을 한 번에 모두 작성하여 오류를 양산하지 않고, 하나의 컴포넌트(Step)를 완전히 만들고 UI에 정상적으로 표시되는지 시각적/기능적으로 검증한 뒤 다음 단계로 넘어가는 1-by-1 원칙을 철저히 준수합니다.

## 🚀 작업 우선순위 (Execution Steps)

모든 작업은 아래의 우선순위 순서대로 1-by-1 원칙에 따라 진행 및 검증됩니다.

### [Step 1] 뼈대 공사: 메인 네비게이션 연동 및 레이아웃 분할
* 작업: 
  1. Views/EnforcementStatusView.xaml (UserControl) 깡통 파일 생성.
  2. MainWindow.xaml의 좌측 사이드바 클릭 시 해당 View가 화면에 나타나도록 라우팅/바인딩 연결.
  3. EnforcementStatusView.xaml 내부에 4개의 Row를 가진 기본 Grid 레이아웃 구성.
* 검증: 사이드바 메뉴 클릭 시 화면이 깜빡임 없이 전환되는지 확인.

### [Step 2] 데이터 뼈대: ViewModel 및 Mock(가짜) 데이터 주입
* 작업: 
  1. ViewModels/EnforcementStatusViewModel.cs 생성.
  2. EnforcementRecord, KpiSummary 등의 모델 구조체 정의.
  3. 화면 렌더링 테스트를 위해 이미지(단속처리현황.png)에 있는 것과 똑같은 Mock 데이터(12건, 3,240만원 등) 하드코딩 주입.
* 검증: 컴파일 에러 여부 확인 및 DataContext 바인딩 정상 작동 여부 확인.

### [Step 3] 상단 UI: KPI 통계 카드 및 검색/필터 바
* 작업: 
  1. 상단 UniformGrid에 그림자 효과가 들어간 5개의 KPI 카드 렌더링.
  2. 텍스트 색상(빨강, 파랑 등)을 ViewModel의 데이터와 바인딩.
  3. 하단의 검색 텍스트박스와 엑셀/인쇄 버튼 배치.
* 검증: 상단 카드의 수치와 색상이 뷰모델 데이터대로 예쁘게 나오는지 확인.

### [Step 4] 핵심 UI: 동적 DataGrid (단속 현황 테이블)
* 작업: 
  1. AutoGenerateColumns="False" 기반의 메인 테이블 렌더링.
  2. 둥근 모서리(Pill) 형태의 배지(Border)를 컬럼 데이터 템플릿으로 적용.
  3. 상태값("이의신청", "체납")에 따른 DataGrid 행(Row) 배경색 변화 트리거(DataTrigger) 구현.
  4. 상태별 액션 버튼([상세], [독촉장] 등) 구현.
* 검증: 표의 데이터가 이미지와 똑같이 보이고 상태별로 색상 배지가 다르게 나타나는지 확인.

### [Step 5] 하단 패널 (좌): 위반자 이력 연동
* 작업: 
  1. 메인 테이블에서 특정 행(Row)을 선택(SelectedItem)했을 때 하단 위반자 프로필과 이력 테이블이 반응하도록 바인딩.
  2. "위험" 등의 아이콘 및 누적 과태료 박스 디자인.
* 검증: 메인 테이블 클릭 시 좌측 하단 정보가 즉시 갱신되는지 확인.

### [Step 6] 하단 패널 (우): 구글 맵 (WebView2) 연동
* 작업: 
  1. WebView2 컨트롤을 우측 하단 패널에 배치.
  2. 선택된 단속 건의 위치 정보를 기반으로 구글 맵(또는 오픈 마커)을 로드.
* 검증: 화면 로드 시 지도가 깨지지 않고 나타나는지 확인.

### [Step 7] 팝업 (모달): 다이얼로그 연동
* 작업: 
  1. MaterialDesign의 DialogHost를 화면 최상단 래퍼로 적용.
  2. 데이터그리드의 액션 버튼(예: "심사") 클릭 시 화면 중앙에 오버레이 팝업이 뜨도록 커맨드 연결.
* 검증: 배경이 어두워지며 중앙 팝업이 자연스럽게 나타나고 닫히는지 확인.

---

## 🛠 결론
이 계획은 "한 번에 하나씩 만들고 눈으로 확인한다(1-by-1)"는 원칙 아래 수립되었습니다.
가장 먼저 [Step 1]과 [Step 2]를 통해 화면 스위칭과 데이터 뼈대부터 확실히 잡은 후 UI 살을 붙여 나갈 것입니다.

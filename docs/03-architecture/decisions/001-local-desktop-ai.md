# 설계 결정: 로컬 데스크톱과 AI 서버 분리

상태: 구현에 근거한 결정 정리 / 검토일: 2026-11-17.

- WPF는 UI·영상 재생, Python은 모델 추론을 담당한다. 기존 .NET UI 자산과 Python 모델 생태계를 함께 이용하기 위한 구조다.
- WebSocket은 분석 결과를 화면에 전달하고 HTTP는 준비·자원 상태를 확인한다.
- SQLite 공유는 로컬 데모 배포를 단순화하지만 두 런타임의 스키마·쓰기 정책을 맞춰야 한다.
- Qwen2.5-VL-3B와 4-bit CUDA 로드는 10GB VRAM 환경을 고려한 현재 선택이다. 이전 모델 비교는 과거 기록에 보존하며 수치 비교를 새로 측정한 결과로 가장하지 않는다.
- 이번 리팩토링은 가중치·프롬프트·판정 기준을 바꾸지 않고 경로와 책임을 먼저 분리한다.

대안: 다중 사용자 운영 시 DB를 API 뒤로 옮기고 작업 큐·인증·감사를 별도 설계해야 한다. 현재 범위에는 포함하지 않는다.

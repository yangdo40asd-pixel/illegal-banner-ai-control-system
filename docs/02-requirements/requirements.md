# 요구사항과 제약

상태: 구현 기준 정리 / 최종 검토: 2026-11-17.

| ID | 요구사항 | 확인 방법 |
|---|---|---|
| FR-CCTV-01 | 네 개 로컬 영상을 재생하고 탐지 박스를 표시한다 | 화면·채널 배치 검사 |
| FR-CCTV-02 | 탐지 0건이면 이전 박스를 제거한다 | 자동시험 |
| FR-VLM-01 | 이미지별 문자·맥락과 판정 결과를 표시한다 | GPU 샘플·UI 수신 |
| FR-REVIEW-01 | 사람 판정을 저장하고 처리 목록과 연계한다 | DB 트랜잭션 시험 |
| FR-ENF-01 | 단속 목록·접수·검토·증거를 조회한다 | DB 상태 및 화면 |
| FR-REPORT-01 | PDF·Excel을 생성한다 | 파일 생성 시험 |
| FR-STATUS-01 | 서버 연결·모델 준비·GPU 상태를 구분한다 | HTTP/WS·상태 시험 |
| NFR-PATH-01 | 개인 PC 경로 없이 설정으로 자원을 찾는다 | cwd 변경·별도 경로 시험 |
| NFR-DATA-01 | 이동·재시작 후 기록을 보존한다 | DB 행 수·무결성 검사 |
| NFR-LIFECYCLE-01 | 외부 서버를 임의 종료하지 않는다 | 소유권 회귀 시험 |
| NFR-REPRO-01 | 코드·모델·환경·시험 근거를 연결한다 | manifest·lock·문서 검증 |

## 제약

검증 플랫폼은 Windows, .NET 9와 Python 3.13이다. 현재 고정 AI 환경은 CUDA 12.6 wheel을 사용한다. CPU에서의 전체 VLM 성능은 검증하지 않았다. 실제 데이터의 공개 범위와 학교별 제출 항목은 별도 확인이 필요하다.

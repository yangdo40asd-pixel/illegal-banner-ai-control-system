# 주요 사용 사례

상태: 현행 / 최종 검토: 2026-11-17.

1. 앱을 켜면 기존 서버를 확인하거나 자식 서버를 시작하고 AI 모델을 준비한다.
2. CCTV 모니터링에서 로컬 영상 4채널과 YOLO 탐지 결과를 확인한다.
3. VLM 검증에서 폴더 이미지의 분석 결과를 선택해 원본·크롭·문자를 검토한다.
4. 합법·불법·재검토를 선택하면 표준 코드로 저장한다.
5. 단속 처리 현황에서 대상 건의 증거·유사 이력·상태를 확인하고 접수·검토를 진행한다.
6. 필요한 보고서를 생성하고 통계를 조회한다.

미디어 누락, 모델 누락, 서버 단절은 정상 분석 완료와 구분한다. 모델 초기 다운로드가 끝나지 않은 경우에는 준비 시간이 추가된다.

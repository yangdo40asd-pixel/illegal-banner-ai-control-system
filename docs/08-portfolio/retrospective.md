# 기술 회고

## 상태 표시와 실제 서버의 차이

과거에는 GPU 수치 초기값과 단순 연결 문구가 실제 모델 준비를 설명하지 못했다. 이후 `/health`와 자원 상태를 연결했다. 이번 실행에서는 실제 GPU 결과와 CPU mock 시험을 구분해 기록했다.

## 경로가 설계의 일부라는 점

데모 미디어는 WPF 소스와 다른 `WPF/`, 운영 DB는 실험처럼 보이는 `inference_test/`에 있었다. 폴더 이동 전에 공통 경로 계약을 만들고 기존 위치에서 먼저 검증한 뒤 이동했다.

## 큰 파일의 점진 분리

AI 클래스 전체를 다시 작성하기보다 메서드 본문을 보존한 채 추출하고 AST를 비교했다. C# DB는 public 진입점과 namespace를 유지하는 partial 분리로 변경 폭을 줄였다. 이는 의존성 주입과 저장 API 분리의 최종 형태를 완성했다는 의미는 아니다.

## 데이터 보존과 회귀 근거

DB는 파일 이동만 하지 않고 SQLite 백업·행 수·무결성을 비교했다. 같은 학습 가중치를 해시로 확인했다. 과거 체크리스트의 완료 표시를 새로운 실행 결과로 대체하지 않았다.

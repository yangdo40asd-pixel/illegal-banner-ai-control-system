# 개인 기여 정리

상태: 근거 목록 / 최종 검토: 2026-11-17.

아래는 현재 저장소에서 확인 가능한 구현 영역이다. 실제 제출 전 본인이 직접 수행한 범위, 협업한 범위, 도구의 도움을 받은 범위를 확인해 서술해야 한다. 이 문서 자체로 특정 사람의 단독 기여를 단정하지 않는다.

| 설명할 구현 | 근거 위치 | 제출 시 정리할 내용 |
|---|---|---|
| WPF 관제 화면·MVVM | src/desktop/BannerGuardSystem | 담당 화면·상태·Command 설계 |
| AI 탐지·문맥 분석 | src/backend/app/inference | 탐지 모델 학습·VLM 선택·파싱 개선 |
| 프로세스·통신 | Communication, core/ai_runtime | 앱과 AI 서버 연결·종료·재연결 |
| DB·판정·단속 | Persistence, database | 중복 방지·트랜잭션·스키마 |
| 검증·문제 해결 | tests, docs/archive, docs/06-testing | 실패 사례·원인·수정·시험 증거 |
| 포트폴리오 리팩토링 | docs/09-planning, scripts | 경로 제거·역할 분리·재현성 개선 |

문장 예시는 “문제가 무엇이었고, 어떤 대안을 비교했으며, 어떤 구현과 시험으로 개선했는가” 순서로 작성한다. 수치가 없는 항목에 개선율이나 정확도를 임의로 넣지 않는다.

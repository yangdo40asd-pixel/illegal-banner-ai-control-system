■ 5. "YOLO가 안 된다" — 서버 vs 화면
--------------------------------------------------------------------------------

  [서버] YOLO 정상 동작
    - YOLO 단독 테스트: 7/8장 탐지, 0.1~0.2초/장
    - 성공 배치에서 CroppedImageBase64 로드 로그 존재 (예: 190999 bytes)
      → 크롭 생성 = YOLO 탐지 완료 증거

  [화면] YOLO가 안 보이는 이유
    Controls\YoloBBoxOverlay.xaml.cs:
      - YoloOverlayMath.IsValid() → bbox Width/Height > 0 만 유효
      - alerts.Count == 0 이면 early return
      - FullImageBase64 배경도 그리지 않음

    optimize.jpg (YOLO 0건):
      → _make_vlm_no_detection_event() → bbox = 0,0,0,0
      → 스냅샷·박스 전부 미표시

    → "YOLO 미실행"이 아니라 "UI에 박스·스냅샷 미렌더" 현상 가능성 큼.


■ 6. 부가 이슈
--------------------------------------------------------------------------------

  (1) BannerAlert 검증 오류 (간헐적)
      로그:
        validation error for BannerAlert — Confidence
        input_value='높음' (문자열이 float 필드에 들어감)
      영향: 해당 이미지(4c880145205ed9.jpg 등) WebSocket 전송 실패 → Feed 미표시

  (2) 자동화 OFF
      is_automation = False 시 _run_inference_raw() 즉시 [] 반환
      → YOLO·VLM 모두 스킵
      → 상단 「자동화 OFF」 토글 확인 필요

  (3) 앱 조기 종료
      로그에 「백엔드 종료 요청」 직후 WebSocket 끊김 반복
      → VLM 사이클 중간 서버 kill → 2장 이후 전송 중단

  (4) 앱 재시작 시 AI 모델 재로드
      Qwen 모델 로드에 약 10~15초 추가 → 첫 VLM 배치 더 늦어짐

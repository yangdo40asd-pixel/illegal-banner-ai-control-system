이 값은 해당 학습 실행의 검증 결과이며 `best.pt`에 대한 새 독립 test 평가 결과가 아니다. 학습 당시 설정·곡선은 같은 실험 폴더에 보존했다. 증강 전 원본 이미지가 분할 간 섞이지 않았는지는 별도 점검 항목이다.

## 리팩토링 후 실행 확인

- RTX 3080에서 YOLO 결과 텐서의 `cuda:0` 사용과 샘플 현수막 1개 탐지를 확인했다.
- 캐시된 Qwen으로 원본 이미지 1장의 VLM 분석 완료를 확인했다. 모델 로딩을 포함한 관측 시간은 약 42.66초였다.
- 이 측정은 워밍업 조건을 통제한 벤치마크나 전체 데이터 정확도가 아니다.

원시 결과는 로컬 `runtime/test-results/gpu-yolo.json`, `gpu-vlm.json`에 있다. 전체 VLM 정확도는 정답셋·표본 수·수동 검토 비율·오류 사례를 정한 별도 평가가 필요하다.
